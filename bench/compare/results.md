# Zinkite, Goose, C++ and Rust

Generated by `bench/compare/run.py` on 2026-11-23 12:11. Don't edit by hand.

Each time is the best of several whole-process runs, after a discarded warm-up: it
includes generating the input, building the structures and tearing them down. Memory
is the peak resident set at the largest size. Every implementation of a benchmark
prints the same checksum lines; a time marked ✗ printed something else and is left out
of the comparisons.
